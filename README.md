# White Glove

Лендинг обучения клинингу с Марией Манукян. Страница собрана на HTML, CSS и небольшом нативном JavaScript.

Открой `index.html` или запусти любой локальный статический сервер. Для GitHub Pages выбери ветку `main` и корень `/` в настройках репозитория.

Фотографии, использованные на сайте: `instagram/maria.jpg` и `instagram/commercial.jpg`.
