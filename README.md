# MONTAL — Мария Манукян

Сайт индивидуального наставничества для тех, кто хочет открыть клининговый бизнес или развить действующую компанию.

## Запуск на компьютере

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Для проверки сборки:

```bash
npm run build
npm run preview
```

## Публикация

Изменения в ветке `main` запускают сборку и публикацию на GitHub Pages. Собранный сайт находится в папке `dist`.

## Структура

- `src/App.jsx` — блоки сайта, навигация и раскрывающиеся ответы.
- `src/index.css` — оформление, адаптивность и анимации.
- `src/main.jsx` — запуск приложения.
- `vite.config.js` — базовый путь для GitHub Pages.

Ссылки на связь ведут в профиль Марии в Instagram. Декоративные фотоблоки — временные заглушки для замены на реальные фотографии; они не изображают Марию и не выдаются за фотографии из её практики.
